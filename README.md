# BTCUSD Auto Scalper Bot (Visual Paper Trading via TradingView)

## Description

- Uses OKX API for BTCUSD price feed
- Technical indicators: RSI, VWAP, Bollinger Bands
- Executes paper trades on TradingView via screen automation (no real funds)

## Setup

1. Install requirements:

```bash
pip install -r requirements.txt
```
